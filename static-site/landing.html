02 Features

Everything you need to share files

Built for developers and power users who want full control without sacrificing usability.

01

File Storage

Upload and organize files in a structured folder tree. Your own private bucket, accessible anytime.

02

Targeted Sharing

Share files directly with registered users. Set expiry times and track what you’ve sent.

03

Quick Share Links

Generate one-time download links for any file instantly — no account required on the recipient side.

04

Received Files

Files shared with you appear in your inbox. Preview inline or download — always organised.

05

Workspaces

Create multiple workspaces to isolate teams, projects, and data domains with clean switching.

06

API Keys

Generate and revoke workspace and private API keys for automated uploads and secure integrations.

07

File Preview

Preview images, PDFs, and text files directly in the browser — no download needed.

08

Private by Default

Every file is private until you explicitly share it. Signed tokens protect every download.

09

Self-Hostable

Deploy FluxSend on your own infrastructure. Full control over your data and storage backend.
